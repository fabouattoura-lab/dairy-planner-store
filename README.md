# dairy-planner-store
DiaryPlanner Store est une plateforme e-commerce dédiée à la vente de diaries et planners variés. Le site permet aux utilisateurs de consulter le catalogue, acheter en ligne, gérer commandes et paiements, tandis que l’administrateur gère produits, stocks et clients. L’objectif est de faciliter l’organisation personnelle via une boutique numérique.
